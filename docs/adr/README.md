## ADR Lifecycle

- **Proposed**: Under discussion and design review.
- **Accepted**: Decision approved for implementation or active in codebase.
- **Rejected**: Evaluated but not adopted.
- **Superseded**: Replaced by a newer decision (link to superseding ADR).
- **Deprecated**: Retired architectural pattern or technology.

## Creating a New ADR

1. Copy [`template.md`](./template.md) to `XXXX-<title-in-kebab-case>.md`.
2. Document context, alternatives evaluated, decision rationale, and operational trade-offs.
3. Update the index table above.
